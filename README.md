# Still I Rise

PWA de treino, alimentação e hábitos focada em manutenção do peso. JavaScript puro, sem backend.

- Código-fonte: `src/`
- Gerar o app: `node build.js` (saída em `docs/`, servida pelo GitHub Pages)
- Ao atualizar, aumente a versão `V` em `src/sw.js` para o celular baixar a nova versão.
